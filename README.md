# PirateGrok

Ashwake Vault, a short retro first-person crawler on a pirate ship.

## Run

```bash
npm install
npm run dev
```

Open http://127.0.0.1:8080

- Desktop: click the view, then look with the mouse. Move with WASD. Quick attack, heavy attack, and block.
- Phone: left stick moves. Drag the right side of the screen to look.
